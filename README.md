جوال واحد يكفي الجلسة كلها، بدون تسجيل وبدون تحميل، ويشتغل حتى بدون نت.

### 🏆 بطولة السهرة

وضع يجمع الألعاب في سهرة وحدة: تسجّلون الفرق مرة وحدة، تختارون لعبتين أو أكثر من عشر ألعاب، والنقاط تتجمّع من لعبة للعبة.

- فوزك على فريق في أي لعبة يعطيك نقطتين في ترتيب البطولة، والتعادل نقطة.
- آخر لعبة هي الذهبية ونقاطها مضاعفة، فالحسم دايماً في النهاية.
- الترتيب ينحفظ على الجهاز، فلو طلعتوا تقدرون تكمّلون البطولة من نفس المكان.
- في الوضع النهاري يتغيّر لونها واسمها إلى «بطولة العصرية». الاسمين في `nameEl` داخل `assets/js/games/tour.js`.

## العلم ورا الوناسة

التصميم مبني على مبادئ معروفة في أبحاث تصميم الألعاب. هذي المبادئ ترفع احتمال إن اللعبة تمسك الجلسة، لكن الحكم الأخير دايماً للتجربة مع ناس حقيقيين.

| المبدأ | كيف طبّقناه | المرجع |
| --- | --- | --- |
| **التدفّق**: التحدي على قد المهارة | اختيار مستوى الجرأة في «الفطاحلة»، أحجام مختلفة للوحة «تطابق»، وأوقات قابلة للتعديل | Csikszentmihalyi, *Flow* (1990) |
| **نظرية التحديد الذاتي**: حرية، إنجاز، قُرب | اللاعب يختار المجال والمخاطرة، النتيجة تظهر فوراً، وكل الألعاب وجهاً لوجه | Ryan, Rigby & Przybylski (2006) |
| **مفاتيح المتعة الأربعة** | المكتبة تغطّي متعة التحدي (الفطاحلة، المبارزة)، الاستكشاف (اللهجات، الإيموجي)، الناس (الدخيل، مين فينا)، والمعنى (الأمثال) | Lazzaro (2004) |
| **إطار MDA** | بدأنا من الشعور المطلوب (ضحك، حماس، سوالف) ثم بنينا القوانين | Hunicke, LeBlanc & Zubek (2004) |
| **قاعدة القمة والنهاية** | جولة ذهبية مضاعفة، تتويج، قصاصات ملوّنة، وألقاب في الختام | Kahneman et al. (1993) |
| **الاستجابة الفورية (Juiciness)** | صوت وحركة واهتزاز مع كل لمسة | Hicks et al. (2019) |
| **الغموض** | دخيل مخفي، وقت قنبلة عشوائي، دوران الدلّة | Costikyan, *Uncertainty in Games* (2013) |
| **سهولة الدخول** | كل لعبة تنشرح في ثلاث خطوات، وتقدر توقفها أي وقت | Juul, *A Casual Revolution* (2010) |

### ليش كل لعبة تمسك الجلسة

| اللعبة | الفكرة التصميمية |
| --- | --- |
| ✍️ **إنسان حيوان جماد** | لعبة يعرفها كل بيت، فما تحتاج شرح. الموقع ياخذ عنكم الأشياء المملّة (اختيار الحرف، الوقت، جمع النقاط) ويترك لكم المتعة. |
| 🧠 **الفطاحلة** | أنتم تختارون الصعوبة فيبقى التحدي على قد مهارتكم (التدفّق)، والسرقة تخلّي الفريق الثاني منتبه حتى في غير دوره، والجولة الذهبية تعطي المتأخر أمل للنهاية. |
| 💣 **القنبلة** | الوقت المخفي يصنع توتر ممتع يتصاعد مع صوت التكتكة، وكل لاعب مشارك في كل ثانية فما فيه انتظار ممل. |
| 🎭 **بدون كلام** | الضحك هنا يجي من الحركة والخروج عن المألوف، وضغط الوقت يرفع الحماس بدون ما يحتاج أحد معلومات مسبقة، فالصغير والكبير متساوين. |
| 🃏 **تطابق** | قوانينها تنفهم من أول قلبة، فهي أحسن لعبة تجمع طفل عمره خمس سنين مع جدّه. والصغار غالباً يغلبون الكبار فيها، وهذا يعطيهم ثقة. |
| 🫖 **دوّر الدلّة** | دوران الدلّة لحظة ترقّب يعيشها الكل مع بعض، والاختيار بين الصراحة والتحدّي يعطي اللاعب تحكّم بمستوى الجرأة اللي يرتاح له. |
| 🧩 **فكّ الإيموجي** | لحظة «آها!» لما تنفكّ الشفرة من ألذّ مشاعر اللعب، واللعب في نفس الوقت يخلّي كل الجلسة مشدودة بدون انتظار دور. |
| 🎯 **كم تتوقع؟** | في أسئلة التقدير ما أحد يعرف الجواب بالضبط، فالكل عنده فرصة يفوز حتى اللي معلوماته أقل. وهذا يخلّي المنافسة متقاربة وممتعة لكل الأعمار. |
| 📜 **كمّل المثل** | متعة المعنى: اللعبة تربط الأجيال ببعض، فالجد يشرح والحفيد يضحك على الاختيارات الغلط. والنتيجة الفورية بعد كل سؤال تعطي إحساس الإنجاز. |
| 🤐 **لا تقولها** | القيد هو مصدر المتعة: لما تنمنع الكلمات السهلة يضطر العقل يبدع، والفريق الخصم مشغول بالمراقبة فما فيه أحد جالس بدون دور. |
| 🤔 **لو خيّروك** | ما فيه جواب صح ولا غلط، فما أحد يخاف يشارك. اللعبة تفتح سوالف وتعرّفكم على بعض، وهذي «متعة الناس» اللي تخلّي الجمعة تطول. |
| 🦅 **مبارزة الصقر** | جولة مدتها ثواني ونتيجتها فورية، فتدمن عليها. والحيوانات المخادعة تضيف اختبار ضبط نفس، مو بس سرعة، فتتساوى الفرص بين الصغير والكبير. |
| 🕵️ **مين الدخيل؟** | المعلومة المخفية تولّد شك وضحك وتمثيل، وكل جولة قصيرة تخلّي الكل يقول «جولة ثانية». هذا النوع من ألعاب الاستنتاج الاجتماعي يعتمد على الغموض كمصدر أساسي للتشويق. |
| 👉 **مين فينا؟** | التأشير في نفس اللحظة يصنع مفاجأة جماعية وضحكة فورية، والألقاب في النهاية تعطي ختام يتذكّره الكل (قاعدة القمة والنهاية). |
| 🗣️ **وش معناها؟** | الفضول يحرّك اللعب: كل واحد يبي يعرف هل كلمة ديرته موجودة، واللي من منطقة ثانية يكتشف شي جديد. الاستكشاف واحد من مفاتيح المتعة الأربعة. |
| 🏆 **بطولة السهرة** | نقاط تتراكم بين الألعاب تعطي السهرة كلها هدف واحد، واللعبة الذهبية المضاعفة تخلّي المتأخر في المنافسة لآخر لحظة. |

هذي الملاحظات للفريق اللي يطوّر الموقع، وما تظهر للّاعبين في الواجهة.

قرارات إضافية مبنية على نفس الأبحاث:

- **ما فيه وقت ميّت**: فرصة السرقة في «الفطاحلة» ومراقب الممنوعات في «لا تقولها» يخلّون الفريق الثاني مشغول في غير دوره.
- **فرصة للمتأخر**: الجولة الذهبية تضاعف النقاط عشان ما أحد يستسلم بدري.
- **تساوي الفرص بين الأعمار**: ألعاب التقدير والذاكرة وردّة الفعل ما تحتاج معلومات، فالصغير ينافس الكبير.
- **محتوى ما يتكرر**: الموقع يتذكّر الأسئلة اللي طلعت وما يعيدها لين تخلص كلها.

## التشغيل

الموقع ملفات ثابتة بدون أي أدوات بناء.

```bash
# افتح index.html مباشرة في المتصفح، أو شغّل خادم محلي:
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

### النشر على GitHub Pages

الموقع منشور من فرع `gh-pages`. أي تحديث يوصل لهذا الفرع ينزل على الموقع خلال دقيقة تقريباً:

```bash
git push origin <فرع-التطوير>:gh-pages
```

بعد أول زيارة يشتغل الموقع بدون نت، وتقدر تثبّته على الجوال من «إضافة إلى الشاشة الرئيسية».

## بنية الملفات

```
index.html                 الصفحة
sw.js · manifest.webmanifest   التشغيل بدون نت والتثبيت كتطبيق
assets/css/style.css       التصميم كله (ثيم ليلي ونهاري)
assets/js/core.js          النواة: التنقّل، الصوت، العدّاد، الفرق واللاعبين، النتائج
assets/js/engines.js       محرّكات مشتركة (فريق ضد الوقت، اختبار اختيارات)
assets/js/data/*.js        المحتوى: الأسئلة والكلمات والأمثال (الملفات اللي آخرها ‎-2 هي الحزمة الثانية)
assets/js/games/*.js       الألعاب، و tour.js لبطولة السهرة
assets/fonts/              خطوط Lalezar و Readex Pro (رخصة OFL)
```

## إضافة محتوى

كل المحتوى في `assets/js/data/` بصيغة بسيطة، وأي سطر تضيفه يدخل اللعبة مباشرة:

```js
// trivia.js — [المستوى 1-3، السؤال، الجواب الصحيح، ثلاث إجابات خطأ، معلومة اختيارية]
[2, 'ما العاصمة الإدارية لمنطقة القصيم؟', 'بريدة', 'عنيزة', 'الرس', 'حائل'],

// quiz.js (الأمثال) — [بداية المثل، التكملة، ثلاث تكملات خطأ، المعنى]
['الجار قبل…', 'الدار', 'الإيجار', 'العزيمة', 'المكيّف', 'اسأل عن الجيران قبل ما تختار البيت.'],

// words.js (لا تقولها) — [الكلمة، الكلمات الممنوعة]
['كبسة', ['رز', 'لحم', 'دجاج', 'غدا', 'أكلة']],
```

## إضافة لعبة جديدة

```js
SH.add({
  id: 'mygame', name: 'اسم اللعبة', emoji: '🎲', color: 'teal',
  tagline: 'وصف قصير', players: '2 إلى 6', time: '10 د', moods: ['laugh'],
  how: ['الخطوة الأولى', 'الخطوة الثانية', 'الخطوة الثالثة'],
  start(ctx) {
    ctx.intro({ setup: 'players', min: 2, max: 6, onStart(cfg) { /* cfg.players */ } });
  },
});
```

ثم أضف ملفها في `index.html` وفي قائمة `sw.js`، وغيّر رقم النسخة `CACHE` في `sw.js` عشان يوصل التحديث للّي ثبّتوا الموقع.

عشان تدخل اللعبة في بطولة السهرة لازم تكون لعبة فرق أو لاعبين تنتهي بـ `ctx.results({ rows })`، ثم أضف معرّفها في قائمة `ORDER` داخل `assets/js/games/tour.js`.
